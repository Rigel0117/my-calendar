# Discord に予定の通知を送る設定

予定ごとに「何分前に通知するか」を決めておくと、その時間に Discord に通知が届きます。
スマホとPCの Discord アプリにプッシュ通知が出るので、スマホへの通知はこれで受け取れます。

送る役目は **Google Apps Script（無料）** が担当します。1分おきに予定を確認するので、PCやスマホの電源が切れていても届きます。所要時間は10分ほどです。

## 1. Discord で通知用のチャンネルを用意する

1. Discord で、自分だけのサーバーを作ります（左の「＋」→「オリジナルの作成」→「自分と友達のため」）。すでにあるサーバーでも構いません。
2. 通知を受け取るチャンネル（例：`#カレンダー通知`）を作ります。
3. そのチャンネルの歯車（チャンネルの編集）→「連携サービス」→「ウェブフック」→「新しいウェブフック」を押します。
4. 「ウェブフックURLをコピー」を押します。これがあとで使う **Webhook URL** です。
5. チャンネル名を右クリック（スマホは長押し）→「通知設定」→ **「すべてのメッセージ」** にします。
   これにしないと、スマホにプッシュ通知が出ないことがあります。
6. スマホの「設定」アプリで、Discord の通知がオンになっていることを確認します。

## 2. Google Apps Script に通知の仕組みを入れる

1. Google にログインした状態で https://script.new を開きます（新しいスクリプトが作られます）。
2. 左上の「無題のプロジェクト」を押して、名前を「マイカレンダー通知」に変えます。
3. 画面に最初から入っている文字をすべて消し、`notify/discord-notify.gs` の中身をすべて貼り付けます。
4. 上の方にある次の2行を書き換えます。
   - `GITHUB_TOKEN` … アプリの同期で使っているのと同じトークン（`ghp_` で始まる文字列）
   - `DISCORD_WEBHOOK_URL` … 手順1でコピーした Webhook URL
5. Ctrl + S で保存します。
6. 上のメニューで実行する関数を **`setup`** にして「実行」を押します。
7. 「承認が必要です」と出たら「権限を確認」→ 自分のGoogleアカウントを選びます。
   「このアプリは Google で確認されていません」と出たら、「詳細」→「マイカレンダー通知（安全ではないページ）に移動」→「許可」を押します。自分で作ったスクリプトなので、この表示が出ます。
8. Discord のチャンネルに **「✅ マイカレンダーの通知を設定しました」** と届けば完了です。

左のメニューの「トリガー」（時計のマーク）に `checkReminders` が「1分おき」で入っていれば、自動で動いています。

## 使い方

- 予定を追加・編集するときに「通知」を選びます（なし／開始時刻ちょうど／5分前〜1週間前／時間を指定）。
- 「時間を指定…」を選ぶと、45分前のように好きな分数を入れられます。
- 終日の予定は、その日の 9:00 を基準にします（「1日前」なら前日の 9:00 に届きます）。
- 繰り返しの予定は、毎回通知されます。「この日だけ削除」した日には届きません。

## 知っておいてほしいこと

- 予定を追加・変更したアプリがネットにつながって同期した後で、通知の対象になります。オフラインのまま追加した予定は、同期されるまで Discord には届きません。
- Google の仕組み上、通知は最大1分ほど遅れることがあります。
- Windows版のアプリが動いているPCには、Windowsの通知も出ます。PCで Discord も開いていると同じ通知が2回出るので、気になる場合はPCの Discord でこのチャンネルを「ミュート」にしてください。
- 通知を止めたいときは、Apps Script の「トリガー」から `checkReminders` を削除します。
- GitHubのトークンを作り直した場合は、ここの `GITHUB_TOKEN` も書き換えてください。
